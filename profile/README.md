## CSG 3023 Intro to Game Programming

Introduction to the design, writing, testing, and documentation of 2D and 3D computer games. Major topics
include animation, physics, sound, user control, state maintenance, and game artificial intelligence. An emphasis
is placed on design and implementation.

*Prerequisite: CS 2003 Fundamentals of Algorithms*

## 🕹️ Unity Certification Objectives
This course includes focused objectives on Unity, covering core concepts and skills aligned with the Unity Associate Certification. Students will gain hands-on experience with essential Unity tools, workflows, and best practices, enabling them to design, implement, and optimize interactive 3D projects. The following objectives highlight the Unity-specific competencies that will be developed throughout the course.
- **Identify and use essential features of Real-Time Engines.**
  - Navigate the user interface

- **Create and manage scene assets and tools effectively.**
  - Create and manage scene elements
  - Export, Import, and Manage assets
  - Identify, configure, and evaluate external assets and tools
  - Create and manage nested objects (e.g., prefabs, actor blueprints, collection assets)

- **Implement physics, raycasting, and collision techniques for optimized scene interactions.**
  - Apply physics principles to objects
  - Using Occlusion, Interference, and Raycasts
    
- **Design and implement interactive, responsive UI components.**
  - Create Interactive UI components
  - Design responsive UI components

- **Manage and complete projects adhering to professional standards.**
  - Evaluate various real-time 3D tools
  - Create and manage real-time projects
  - Manage and plan projects in development cycles
  - Create a professional development portfolio
  - Build and deploy project versions

- **Implement and manage version control for project collaboration and documentation.**
    - Implement version control

- **Create, refactor, and manage object-oriented code, applying best practices to develop and debug.**
  - Analyze and apply object-oriented programming principles
  - Create events and variables
  - Develop scripts with logical flow
  - Control code execution with logical structures
  - Create object components with scripts
  - Debug and refactor code
  - Employ state machines
  - Reuse code with inheritance and polymorphism
  - Recognize and apply data types for specific purposes
